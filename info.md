# Solar Dashboard Card

A responsive solar-powered home visualization for Home Assistant.

- Full-width responsive house image that changes with weather + day/night.
- Four clickable node bubbles (Solar / Home / Battery / Grid) that open more-info.
- Animated bezier SVG energy-flow lines that pulse when active and dim when idle.
- Stats strip, battery card and a quarter cost-estimate card.
- 100% configurable entities, node positions (percentages) and images.
- No build step, no Mushroom / card-mod / Node-RED / extra cards required.

See the [README](https://github.com/your-github-username/solar-dashboard-card) for full configuration.
